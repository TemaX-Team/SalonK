# Definition of Ready (DoR) 

For a ticket to be considered ready for a sprint, all the following requirements must be met: 

The user story has a clear title following the team's naming convention (OWN, CLT, ATS, or STM). 

The user story includes a description explaining what the user wants and why. 

The user story has clear, realistic, and testable acceptance criteria. 

The user story has an estimated development time and a priority assigned in Jira. 

The user story is assigned to the correct Epic and Sprint. 

All dependencies on other user stories, services, or team members have been identified. 

The team understands the requirements and has enough information to begin implementation. 

The user story is small enough to be completed within its assigned sprint. 

A user story that does not meet these requirements should be clarified before development begins. 

 

 

# Definition of Done (DoD) 

For a ticket to be considered done, all the following requirements must be met: 

All acceptance criteria for the user story have been implemented and verified. 

The implementation has been tested using appropriate unit, integration, and end-to-end tests. 

All automated tests pass, and previously implemented features continue to work correctly. 

Code containing business logic has at least 90% automated test coverage, measured using an appropriate .NET testing tool. 

All frontend changes support French and English, with French displayed by default. 

Frontend interfaces follow accessibility standards and work correctly on supported screen sizes. 

Backend endpoints enforce the appropriate authentication, authorization, and input validation. 

A pull request has been created, reviewed, and approved by at least two other team member. 

Changes affecting another team member's work have been reviewed by the affected member. 

The pull request has been successfully merged into the main branch without breaking the build or CI/CD pipeline. 

Any necessary technical documentation has been updated. 

The Jira ticket has been updated and moved to Done only after all requirements above are satisfied.
